# SMP Shorts (Claude plugin)
Unstable SMP / Minecraft footage → viral 9:16 short: auto-picks the best moments, renders its own motion graphics first, edits last, and writes a CapCut PC project by name.

Install: `/plugin marketplace add fahadisthegoat2-hub/motion-forge` → `/plugin install smp-shorts`. Then: `/smp-edit clip.mp4 project:"Ep 12 Betrayal" title:"HE BETRAYED THE WHOLE SERVER"`.
