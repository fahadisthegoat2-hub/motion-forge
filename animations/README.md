# Your animations

Put extra Mixamo animations here (FBX). They automatically work on every character.

1. mixamo.com → pick an animation (e.g. "Waving", "Terrified", "Falling") → **Download**
   → Format **FBX**, Skin **Without Skin**.
2. Upload it here (GitHub → **Add file → Upload files**), e.g. `animations/Terrified.fbx`.
3. Tell Claude: "use the Terrified animation".
