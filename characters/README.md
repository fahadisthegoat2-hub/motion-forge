# Your characters

Put character files here. The scene uses `characters/hero.glb` (or `.fbx`) first, then any
name you list in `CAST`. Without a file, a free sample man is used.

## Best free options (all work on iPad in Safari)
1. **Avaturn** (avaturn.me) — make a realistic person (even from a selfie), export **GLB**.
   Has face shapes → blinking, smiles, shock, talking all work.
2. **Mixamo** (mixamo.com, free Adobe account) — pick a character, download **FBX**.
   Body only (no blinking/face expressions).

## Upload on iPad
GitHub repo page → **Add file → Upload files** → choose the file → name it `hero.glb`
(or `hero.fbx`) → **Commit changes**. Then just tell Claude "use my character".
