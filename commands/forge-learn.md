Use the `reference-learning` skill. Analyze these references: $ARGUMENTS

Run the analyzer script on every image, view each image, infer the underlying rules
(including how this style would move and look beyond what's shown), and save the style
bible to `.motion-forge/styles/`. Finish with a 5-line summary of the style and a
tiny Three.js preset demo (`.motion-forge/styles/<name>-preview.html`) that proves it.
