# motion-forge — Claude Code plugin

Viral 3D story shorts, realistic humans and sets, story writing with twists, reference
style learning, custom animation, motion graphics, on-device MP4 rendering, growth/SEO packs.

## Commands
| Command | Does |
|---|---|
| `/forge-short <premise>` | Full 3D short: twist script → scenes → QA → on-device render → publish pack |
| `/forge-story <premise>` | Hook → escalation → climax → plot-twist script with shot table |
| `/forge-learn <images>` | Learns a reusable style bible from reference images |
| `/forge-3d <idea>` | Polished Three.js scene |
| `/forge-animate <idea>` | Animator-grade motion (12 principles, springs) |
| `/forge-motion <brief>` | Motion graphics → MP4/GIF |
| `/forge-publish <video>` | Titles, description, tags, hashtags, pinned comment |

Skills also trigger automatically. Default tools: Three.js + Node/Playwright + ffmpeg.
Blender/Python are only used if you say **"Blender/Python allowed"**.

## On-device render
Every scene includes a **Render on this device** panel: it reads your CPU/RAM/GPU, picks a
quality tier, renders frame-perfect on your GPU (WebCodecs) and downloads an MP4.
Works in Chrome, Edge and Safari 17+.
