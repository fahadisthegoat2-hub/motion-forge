# Reference images & videos

Drop reference **images or videos** here (or attach images in chat). Claude studies them —
look, lighting, color, editing rhythm, camera moves, pacing — and saves a reusable style in
`.motion-forge/styles/`. It never copies them into your video.

Upload on iPad: GitHub repo → **Add file → Upload files** → pick the image/video → **Commit**.
Then say "study the references".
